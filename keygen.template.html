Licence key generator

Private tool. Never deploy this file to the public site.
Keep this off the server. It contains the salt. If it is published, anyone can mint their own key. Keep it on your machine only.

How to use it. A payment lands in Stripe. Paste the buyer's email here, generate, and send the key in your fulfilment email. The same reference always produces the same key, so if a buyer loses theirs you regenerate rather than looking it up.

What this is not. This is a speed bump, not real licensing. The check runs in the browser and a determined person can bypass it in about a minute. At $39 a copy, a server that would stop them costs more than the leakage. Revisit only if you see keys circulating publicly.

The salt is JJEE1 and it must match KEY_SALT in index.html. Change one and you must change the other, and every key already issued stops working.
